# AI Marketplace Bot

Telegram-бот, который автоматизирует работу продавца на **Wildberries** и **Ozon**: по артикулу и названию товара сам находит информацию, пишет описание и характеристики с помощью ИИ, подбирает фото, рисует инфографику и создаёт карточку через API маркетплейса.

> Проект опубликован как портфолио. Ключи, данные магазина и рабочая база в репозиторий не входят. Использование кода без разрешения автора запрещено, см. [LICENSE](LICENSE).

## Что умеет

- **Создание карточек WB с нуля** (`/wb_create`): определяет категорию, заполняет обязательные характеристики, ТН ВЭД, габариты, загружает фото. Списки товаров обрабатывает пачками и продолжает при ошибке в одной позиции.
- **Описания и характеристики** (`/card`, `/desc`, `/chars`): генерация через LLM с учётом требований категории; можно переключать модель (`/model`: Gemini / DeepSeek / OpenAI).
- **Инфографика**: несколько шаблонов под разные категории (мыши, колонки, игровые девайсы, ОЗУ и т. д.), удаление фона, подбор цветов, водяной знак магазина. Есть бесплатный режим, который рисует всё локально без вызовов ИИ.
- **Подбор фото**: поиск через SearXNG / Exa, оценка кандидатов моделью CLIP и Gemini Vision.
- **Ozon**: заполнение Excel-шаблонов и создание карточек через Seller API, хостинг фото в Cloudflare R2.
- **Видеообложки** для WB (MiniMax / Hailuo).
- **Админка**: учёт расходов на ИИ (`/costs`), проверка состояния API и диска (`/health`), управление доступом пользователей, ежедневный отчёт в Telegram.

## Стек

Python 3.11 · aiogram 3 · aiosqlite · pydantic-settings · httpx / aiohttp
Gemini · DeepSeek · OpenAI · Exa · SearXNG
Pillow · rembg · OpenCV · PyTorch + CLIP · Ultralytics
openpyxl · boto3 (Cloudflare R2)

## Структура

```
main.py              точка входа, регистрация роутеров, планировщик
config.py            настройки из .env
handlers/            команды Telegram (WB, Ozon, карточки, фото, видео, админка)
services/
  card/              категории, бренды, генерация и нормализация карточки
  llm/               провайдеры LLM с общим интерфейсом
  search/            поиск контекста и фото, кэш
  image/             инфографика, фоны, шрифты, CLIP-оценка
  ozon/              клиент Ozon Seller API
  video/             видеообложки
  wb_create.py       конвейер создания карточек WB
prompts/             промпты (в публичной версии скрыты)
database/            SQLite: пользователи, кэш, расходы
utils/               биллинг, отчёты, Excel, вспомогательное
```

## Запуск

1. Python 3.11, затем:
   ```bash
   python -m venv .venv
   .venv\Scripts\activate        # Windows
   pip install -r requirements.txt
   ```
2. Скопируйте `.env.example` в `.env` и заполните свои ключи.
3. (Необязательно) поднимите локальный SearXNG на `127.0.0.1:8888`.
4. `python main.py` или `start.ps1` на Windows.

Для некоторых функций нужны собственные файлы, которых нет в репозитории: Excel-шаблоны категорий, логотип магазина для водяного знака.
